# 🐟 등용문 연못

> 오래 미뤄둔 꿈을 물고기 한 마리로 띄우고,
> 할 일을 하나씩 해낼 때마다 폭포를 한 단씩 거슬러 오르세요.
> 끝까지 오르면 물고기는 용이 되어 연못 하늘의 별이 됩니다.

"잉어가 폭포를 거슬러 오르면 용이 된다"는 **등용문(登龍門)** 이야기를 할 일 앱에 입힌 3D 웹 공유 연못입니다.
설치나 로그인 없이 링크 하나로 들어와서 다른 사람의 꿈 물고기와 함께 헤엄칩니다.

## 핵심 흐름

| 단계 | 하는 일 | 연못에서 |
|---|---|---|
| 방류 | 꿈 한 줄을 적고 물고기(베리·레몬·코랄·네온)를 고른다 | 물고기가 물보라를 일으키며 연못에 들어감 |
| 물길 나누기 | 꿈을 할 일 1~10개로 쪼갠다 | 폭포에 내 진행도 등불이 켜짐 |
| 먹이 | 할 일 하나 완료 | 물 밖으로 뛰어오르고, 몸이 커지고, 등불이 한 단 올라감 |
| 쉼 | 3일간 아무것도 안 함 | 죽지 않고 수초 아래에서 잠듦 (zzz). 하나만 해내면 깨어남 |
| 등용 | 마지막 할 일 완료 | 폭포를 단마다 뛰어올라 금빛이 되고, 홍살문을 지나 하늘로 → 별 |

## 다른 사람과 (자유 채팅 없이)

- **같은 연못**: `?pond=yeon-3` 같은 링크로 같은 방에 모입니다 (방당 최대 24명, 꽉 차면 다음 연못으로 자동 배정).
- **응원 먹이**: 다른 물고기를 누르고 🍚를 주면 수면에서 밥알이 떨어지고, 상대에게 알림이 갑니다.
- **같이 헤엄치기**: 마음에 드는 꿈 물고기 옆에 나란히 붙어 헤엄칩니다.
- **물방울 말**: "응원해요", "같이 가요", "오늘 하나 했어요" 같은 정해진 말만 보낼 수 있습니다. 악플 걱정 없는 조용한 공간을 지키려는 선택입니다.
- **등용 축제**: 누군가의 꿈이 용이 되면 연못 모두의 화면에 꽃잎이 내리고, 그 연못 하늘에 별이 영구히 남습니다.
- **꿈 공개/비공개**: 꿈 문장을 숨기면 다른 사람에게는 진행도만 보입니다.

## 실행

```bash
npm install
npm start
# http://localhost:3000
```

친구와 테스트하려면 같은 `?pond=` 링크를 두 브라우저에서 열어 보세요.

## 구조

```
server.js              정적 파일 + WebSocket 연못 방 서버 (의존성: ws)
public/
  index.html, style.css
  js/main.js           UI ↔ 연못 ↔ 네트워크 연결
  js/world.js          Three.js 장면: 하늘, 연못, 등용문 폭포, 물고기 AI, 효과
  js/net.js            WebSocket 클라이언트 (자동 재연결, 서버 없으면 혼자 모드)
  js/store.js          내 꿈/할 일 (localStorage)
  js/sound.js          WebAudio로 합성하는 물소리·풍경 소리 (파일 없음)
  js/data.js           물고기 종류, 정해진 말, 무작위 이름
  assets/fish/*.glb    물고기 3D 모델 4종 (스킨 애니메이션 포함)
data/stars.json        연못별 등용 기록 (자동 생성, git 제외)
```

- 내 꿈과 할 일은 **브라우저에만** 저장됩니다. 서버는 현재 접속자의 공개 정보(이름, 물고기 종류, 공개한 꿈 문장, 진행도)만 중계하고, 등용한 꿈만 별로 기록합니다.
- 다른 물고기의 위치는 동기화하지 않고 각자 화면에서 시뮬레이션합니다. 상태(진행도·잠·따라가기)와 사건(도약·먹이·말·등용)만 주고받아 가볍습니다.
