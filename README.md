# 🐟 소원 연못

> **소원을 물고기에 담아 연못에 놓아주세요.**
> 내가 주든 친구가 주든 **먹이를 5번** 주면 물고기는 폭포를 거슬러 올라 소원이 이루어지고, 등용문 너머 구름 위 **하늘 연못**의 금빛 물고기가 됩니다.

설치·가입 없이 링크 하나로 들어오는 3D 웹 연못입니다. 소원 하나 = 물고기 한 마리.

## 소원이 보이는 세 층

| 층 | 무엇 | 어떻게 보나 |
|---|---|---|
| **물속** | 지금 응원이 필요한 소원 | 물고기를 누르면 소원 카드 + ✨ 먹이 주기 |
| **수면** | 물고기가 가끔 올라와 소원 한 줄을 띄움 | 가만히 보고만 있어도 남의 소원이 하나씩 읽힘 |
| **하늘 연못** | 먹이 5번을 받아 이루어진 소원 | 금빛 물고기를 누르면 소원 제목 말풍선 + 이루어진 날 |

**하늘 연못** — 이루어진 소원은 사라지지 않고, 폭포 위 구름 사이에 떠 있는 바다처럼 넓은 연못에서 물고기로 계속 헤엄칩니다. 물은 아래 연못과 같은 물(깊이에 따른 색, 하늘·달빛 반사, 물가 물거품)이고, 모래 바닥에 물속 빛 무늬가 일렁이며, 물고기는 깊이만큼 물빛을 입어 물속에 잠겨 보입니다. 아래 연못에서도 등용문 위로 섬의 밑동이 보이고, 등용문에서 금빛 티끌이 섬으로 올라갑니다.

**✦ 하늘 연못** 버튼을 누르면 카메라가 앞쪽 물가 위로 올라가 바다를 바라보고, 물고기를 누르면 그 위에 소원 제목이 말풍선으로 뜨고 카드에 이름과 이루어진 날이 보입니다 (손가락으로도 잘 눌리게 가까운 물고기를 찾아 줌). ‘이루어진 내 소원’이나 모아 보기 목록에서 고르면 카메라가 그 물고기를 따라갑니다. 한 번에 헤엄치는 물고기는 최근 소원부터 40마리(휴대폰 24마리)이고, 그보다 오래된 소원은 목록에서 부르면 다시 올라옵니다.

**하늘 연못에서 놀기**
- 다 올라오면 손가락·마우스로 섬을 **돌려 보고 당겨 볼** 수 있습니다.
- **왕관** — 이루어진 소원의 물고기는 모두 루비 박힌 금관을 쓰고 있고, 가끔 왕관이 반짝입니다.
- **구름다리** — 앞쪽 물 위의 작은 바위섬 두 개를 무지개처럼 잇는 흰 대리석 아치 다리. 금 난간·금 기둥·기둥 위 등불, 꼭대기에 빛나는 금빛 보주, 다리 아래를 구름이 받칩니다.
- **불빛** — 뒤쪽 물가에 대리석 석등 여섯 개, 물 위엔 연꽃 연등이 천천히 떠다니고, 하늘 연못을 보는 동안 물 위로 금빛 반짝임이 피어오릅니다.
- **뛰어넘기** — 물고기가 가끔 물 위로 뛰어오르고, 다리 근처에 있으면 구름다리를 넘어 건너편으로 갑니다 (다리 폭 전체를 난간보다 높이 지나도록 포물선을 잡음).
- **부딪힘** — 아래 연못처럼 몸통을 캡슐로 보고 물고기끼리 서로 통과하지 않게 밀어내고 살짝 튕깁니다. 바위섬 기둥도 뚫지 못하고, 공중에서 구름다리(바닥판·난간·아래 구름)에 닿으면 튕겨 나와 물로 떨어집니다. 다리 아치 밑의 빈 공간으로는 지나갈 수 있습니다.
- **반짝이 뿌리기** — 빈 물을 누르면 금빛 반짝이가 떨어지고 가까운 물고기 네 마리가 몰려옵니다. 지금 접속한 사람들의 화면에도 똑같이 보입니다.
- 물고기 몸 색은 그대로 두고 (덧칠하면 바래 보임), 수면 뒤에 그려 물빛만 깊이만큼 입힙니다.

**내 이름** — 처음 들어오면 ‘색 + 물 단어’ 이름이 자동으로 정해지고(400가지), 패널 맨 위에서 **✏️ 바꾸기**로 직접 적거나 **🎲**로 다시 뽑을 수 있습니다. 바꾸면 이름표와 내 소원들(헤엄치는·이루어진)의 이름도 함께 바뀌어 다른 사람 화면에도 곧바로 보입니다. 욕설·광고 같은 이름은 소원 글과 같은 기준으로 막습니다 (`POST /api/name`).

**이루어진 내 소원** — 목록 대신 패널의 **✦ 이루어진 내 소원 n개 · 하늘 연못에서 보기** 버튼 하나. 누르면 하늘 연못으로 올라가 내 물고기를 따라가고, 한 번 더 누르면 다음 소원으로 넘어갑니다.

**내 소원 지우기** — 헤엄치는 소원이든 하늘 연못의 소원이든 주인만 지울 수 있습니다 (패널·카드·목록의 🗑).

버튼 하나로 **소원 모아 보기**(헤엄치는 소원 / 이루어진 소원 / 내 소원, 새로운 순·곧 이루어질 순)도 열 수 있습니다.

## 함께 있는 느낌

- **지금 접속한 사람**은 소원이 없어도 자기 물고기로 연못에 나타나고, 초록 점이 붙은 **이름표(● 이름)**가 계속 떠 있습니다. 나가면 사라집니다.
- 그 사람이 헤엄치거나, 응원하거나, 연못을 눌러 이동하면 **내 화면에서도 똑같이** 움직입니다.
- 새로 들어온 사람은 “○○ 님이 연못에 들어왔어요”로 알려 줍니다.
- 휴대폰은 왼쪽 위 로고 옆에 **● n명**(지금 접속한 사람 수, 나 포함)이 보이고, 누르면 누가 있는지 이름이 뜹니다.
- **사람 수 세는 법** — 열린 탭·창 하나하나를 한 명으로 셉니다 (같은 브라우저의 내 다른 탭은 숫자엔 들어가지만 내 연못엔 따로 그리지 않고, ● n명을 누르면 ‘나(탭 2개)’로 보임). 페이지를 닫거나 앱을 끄면 바로 나가고, 그렇지 못한 경우(폰 화면 꺼짐·앱을 내린 채 멈춤·네트워크 끊김)도 브라우저가 25초마다 보내는 신호가 75초 넘게 없으면 서버가 30초마다 정리해 숫자와 연못에서 뺍니다. Cloudflare 에서는 이 신호에 Durable Object 가 잠든 채로 답해서 요금이 거의 들지 않습니다.

**아래 버튼 막대 (유리 느낌)**

| 버튼 | 하는 일 |
|---|---|
| 🌊 헤엄 | 내 물고기가 무작위 동작 (질주·맴돌기·공중제비·꼬리 춤·뻐끔뻐끔·활공·바닥 탐색) |
| 🙏 소원 | 소원 적기 / 내 소원 보기 |
| ✨ 먹이주기 | 내 소원에 먹이 (n/5 배지) |
| 💛 응원 | 내 물고기가 빙그르르 돌거나 물 위로 점프 + 하트. 접속한 사람의 물고기 카드를 열어 두고 누르면 그 사람에게 “💛 응원을 보냈어요”가 뜸 |
| 💬 말 | 정해진 말 8개 중 하나를 골라 내 물고기 위에 말풍선으로 띄움 (안녕하세요 · 힘내요 · 꼭 이루어질 거예요 · 나도 같은 소원이에요 …). 접속한 사람의 카드를 열어 두고 고르면 그 사람 화면에 “💬 이름: 말”이 뜨고 말풍선이 노랗게 보임. 자유 채팅이 아니라서 거를 필요가 없음 |

**🐟 같이 헤엄치기** — 접속한 사람의 물고기(또는 그 사람의 소원 물고기) 카드에서 누르면, 내 물고기가 그 물고기 옆에 나란히 붙어 다닙니다. 모든 사람 화면에서 두 물고기가 함께 헤엄치는 모습이 보이고(이름표에 🐟), 상대에게는 “○○ 님이 같이 헤엄쳐요”가 뜹니다. 연못을 누르거나 카드의 “그만 헤엄치기”로 헤어지고, 상대가 나가면 저절로 풀립니다. 따라가는 중에도 헤엄·응원 몸짓은 할 수 있습니다.

## 흐름

0. **내 물고기** — 들어오자마자 ‘나’ 물고기가 연못에 있습니다. 연못을 누르면(휴대폰은 톡) 그 자리로 헤엄쳐 갑니다.
1. **소원 적기** — 한 줄 + 물고기(베리·레몬·코랄·네온). 공개하지 않으면 ‘마음속 소원’으로 보입니다.
2. **목어 세 번** — 두드리면 내 물고기가 그대로 소원을 품고 연못을 헤엄칩니다.
3. **먹이 5번** — ✨ 먹이 주기. 내 소원에도, 남의 소원에도 줄 수 있고 하루 제한은 없습니다 (연타만 막음). 먹이를 받을수록 물고기가 금빛으로 빛납니다.
4. **소원 성취** — 다섯 번째 먹이에 물고기가 폭포를 올라 등용문을 지나 하늘 연못으로 뛰어듭니다 (약 12초). 내 소원이거나 내가 먹이를 준 소원이면 카메라가 따라가다가 마지막에 하늘 연못을 내려다보는 장면으로 봅니다.
5. **링크 공유** — “내 소원에 먹이 주러 와 줘” (`/?wish=<id>`)
6. **다시 왔을 때** — 없는 동안 들어온 먹이, 없는 동안 이루어진 소원의 장면을 보여 줍니다.

**휴대폰** — 처음엔 연못 화면과 아래 버튼 막대만 보입니다. 🙏 소원을 누르면 패널이 올라오고, 카드와 패널은 한 번에 하나만 열립니다.

## 안전장치와 관리자

**소원 거르기** (`core/moderation.js`)
- 욕설·성적 표현, 링크·전화번호·이메일(광고·개인정보)이 들어간 소원은 방생 단계에서 막습니다. 띄어쓰기·기호로 끊어 써도 걸립니다.
- ‘보지 않기’, ‘자지 않고’, ‘시발점’처럼 평범한 말에 섞이는 낱말은 일부러 빼거나 예외로 두었습니다.

**신고** — 소원 카드의 🚩 신고. 서로 다른 **3명**이 신고하면 자동으로 숨겨지고, 관리자가 확인해 다시 보이게 하거나 지웁니다. 숨겨진 소원의 주인에게는 “신고가 들어와 잠시 숨겨졌어요”가 보입니다.

**사람(기기) 구분** — 접속한 **기기의 브라우저마다** 익명 아이디가 하나씩 생깁니다 (휴대폰·컴퓨터는 각각 다른 사람으로, 시크릿 창은 매번 새 사람으로). 내 소원 확인·지우기·횟수 제한은 모두 이 아이디 기준이고, 인터넷 주소(IP)는 같은 와이파이·통신사를 여럿이 함께 쓰는 경우를 고려해 아주 넉넉한 안전망으로만 씁니다.

**연타 막기** — 기기마다 먹이는 1.2초에 한 번(시간당 300번), 소원 방생은 시간당 6번, 신고는 시간당 20번.

**관리자 페이지** — `/admin` (검색 엔진에 안 잡힘)
- 신고된 소원 / 전체 / 헤엄치는 / 별 / 숨긴 소원, 글·이름·ID 검색 (비공개 소원 글도 보임)
- 숨기기 · 다시 보이기 · 신고 지우기 · 삭제, 백업 내려받기(JSON)
- 통계: 전체·오늘 방생·받은 먹이·신고·숨김·지금 접속
- 비밀번호는 `ADMIN_TOKEN` (아래 배포 참고). 설정하지 않으면 관리자 기능은 꺼져 있고, 틀린 비밀번호는 한 시간에 10번까지만 받습니다.

## 서버

규칙(소원 저장, 먹이 규칙, 별)은 **`core/pond.js` 한 곳**에 있고, 두 가지 방식으로 돌릴 수 있습니다.

| | 내 컴퓨터 (`server.js`) | Cloudflare (`src/worker.js`) |
|---|---|---|
| 저장 | `data/wishes.json` 파일 | Durable Object 내장 저장소 (DB 불필요) |
| 실시간 | `ws` | WebSocket Hibernation (조용할 땐 요금이 거의 안 듦) |
| 정적 파일 | Node 가 직접 | Cloudflare 가 바로 (`public/`) |

- 방문자는 브라우저가 만든 익명 아이디를 **해시로만** 보관합니다.
- 한 사람당 헤엄치는 소원은 한 번에 하나, 소원이 이루어지면 새 소원을 띄울 수 있습니다.
- REST: `POST /api/name` (내 이름 바꾸기), `GET /api/stats`, `GET /api/wishes?status=swimming|star&sort=mix|new|near|recent`, `GET /api/wishes?mine=1`, `GET /api/wishes/:id`, `POST /api/wishes`, `POST /api/wishes/:id/feed`, `POST /api/wishes/:id/report`, `POST /api/wishes/:id/delete` (주인만)
- 관리자: `GET /api/admin/stats`, `GET /api/admin/wishes?filter=&q=`, `POST /api/admin/wishes/:id {action}`, `GET /api/admin/export` (헤더 `Authorization: Bearer <ADMIN_TOKEN>`)
- 방문자 아이디는 `x-pond-uid` 헤더로 주고받습니다 (주소창·서버 기록에 남지 않게)
- WebSocket(`/ws`): 서버 → 새 소원·먹이·별·지금 있는 사람(`presence`)·몸짓(`emote`), 클라이언트 → 자기소개(`hello`: 이름·물고기·소원)·몸짓(응원·헤엄·이동). 규칙은 `core/presence.js` (이름 거르기, 몸짓 간격 제한)
- 소원이 이루어지는 먹이 수는 `WISH_GOAL` (기본 5). Cloudflare 는 `wrangler.jsonc` 의 `vars`

## 실행 (내 컴퓨터)

```bash
npm install
npm start
# http://localhost:3000
# 관리자 페이지까지 쓰려면: ADMIN_TOKEN=아무비밀번호 npm start → http://localhost:3000/admin
```

Cloudflare 와 똑같은 환경으로 돌려 보려면 `npm run cf:dev` → http://localhost:8787

## 배포 (Cloudflare Workers, 무료 요금제)

**방법 A — 대시보드에서 GitHub 연결 (설치 없이)**
1. https://dash.cloudflare.com 가입·로그인 (카드 등록 불필요)
2. **Workers & Pages → Create → Import a repository** → GitHub 연결 → `sansa_fish` 선택
3. 설정
   - Project name: `wish-pond`
   - Build command: 비워 둬도 됨 (`wrangler.jsonc` 의 `build` 가 배포 직전에 `npm run build` 로 three.js 를 `public/vendor` 에 복사)
   - Deploy command: `npx wrangler deploy`
   - 브랜치(Production branch): 실제로 고친 코드가 올라가 있는 브랜치. 다른 브랜치에 푸시한 건 미리보기로만 올라가거나 아예 배포되지 않음
4. **Save and Deploy** → `https://wish-pond.<내 하위 도메인>.workers.dev` 주소가 생김. 이후 그 브랜치에 푸시할 때마다 자동 배포
5. **관리자 비밀번호 넣기**: 프로젝트 → **Settings → Variables and Secrets → Add** → Type **Secret**, Name `ADMIN_TOKEN`, Value 에 길고 어려운 비밀번호 → **Deploy**. 이제 `https://…workers.dev/admin` 에서 로그인

**방법 B — 내 컴퓨터에서 명령어로**
```bash
npm install
npx wrangler login
npm run deploy
npx wrangler secret put ADMIN_TOKEN   # 관리자 비밀번호 입력
```

> 무료 요금제는 한도를 넘으면 요금이 나가는 대신 그날 요청이 실패하고 다음 날 풀립니다. 결제 수단을 등록하거나 유료로 바꾸지 않으면 과금되지 않습니다.

## 물 표현 (`public/js/water.js`)

- **수면**: 방향이 다른 파도 여러 겹 + 잔물결 + 물결 고리로 표면 기울기를 만들고, 비스듬히 볼수록 하늘이 비치는 프레넬 반사
- **반사**: 밤하늘 색, 은은한 달빛 길, 석등 근처의 금빛
- **깊이**: 바닥 높이를 셰이더에서도 같은 식으로 계산해 얕은 곳은 맑은 청록, 깊은 곳은 짙은 남청
- **물거품**: 바위와 닿는 가장자리
- **코스틱**: 물을 통과한 빛이 바닥·조약돌·마리모에 만드는 일렁이는 그물무늬
- **물속에서 올려다볼 때**: 위는 열린 창처럼 밝고(스넬의 창), 비스듬히는 어둡게

## 폭포

- **물줄기**: 단 끝에서 앞으로 휘어 넘쳐흐르는 곡면. 세로로 길게 흐르는 물결무늬, 턱 위와 떨어지는 자리의 하얀 거품, 달빛에 반짝이는 물방울
- **떨어지는 자리**: 소용돌이치는 거품과 튀어 오르는 물방울, 맨 아래 연못에는 더 큰 거품과 물안개
- **바위**: 울퉁불퉁한 단, 돌 얼룩과 결, 위를 향한 면에만 자연스럽게 낀 이끼 (연못 둘레 바위·절벽도 같은 재질)
- **절벽**: 틈마다 풀과 작은 덤불

## 연못 장식 (`public/js/decor.js`)

- **연잎**: 잎맥·색 얼룩·V자 틈이 그려진 잎, 가장자리가 살짝 말려 올라가고 물방울이 맺힘. 물 위로 솟은 큰 연잎도 몇 장
- **연꽃**: 숟가락처럼 오목한 꽃잎 3겹(바깥은 활짝, 안쪽은 오므림), 뿌리는 하얗고 끝은 분홍, 노란 연밥과 수술. 줄기 위 봉오리
- **석등**: 한국식 팔각 석등 — 받침돌, 연꽃 받침, 기둥, 창 네 개의 화사석, 모서리가 들린 지붕, 보주. 불빛이 은은히 일렁임
- **연못가**: 풀 포기, 들꽃, 물가의 부들, 디딤돌. 봉오리·부들·솟은 연잎은 바람에 살랑임

## 물리

- **바닥**: 바닥 모양과 충돌이 같은 함수(`floorHeight`)를 쓰므로 가장자리 경사에서도 뚫고 들어가지 않습니다. 몸이 기울면 머리·꼬리 끝까지 계산하고, 세게 부딪히면 모래가 일어납니다.
- **물고기끼리**: 몸을 캡슐로 보고 겹치면 무게(크기) 비율로 밀어내고 반발 계수 0.35로 튕깁니다. 세게 부딪히면 몸을 흔들고, 놀란 물고기는 반대쪽으로 질주합니다. 부딪히기 전에 살짝 비켜 가는 개인 공간도 있습니다.
- **벽·수면**: 가장자리는 미리 피하고, 닿으면 튕겨 나옵니다. 도약할 때만 수면을 넘습니다.
- **도약**: 수면을 향해 차고 올라 → 공중에서는 중력만 받는 포물선 → 물에 떨어지면 저항으로 감속하고 부력으로 돌아옵니다.
- **수초·연잎**: 수초는 끝으로 갈수록 가늘어지는 리본 잎 여러 장으로 된 포기(초록·올리브·청록, 가끔 붉은 해초)이고, 물살에 끝부분이 하늘거립니다. 지나가는 물고기에 밀려 휘었다가 돌아오고, 연잎은 밀려나며 들썩입니다. 수면 가까이 빠르게 지나가면 물결이 남습니다.
